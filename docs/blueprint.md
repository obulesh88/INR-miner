# **App Name**: Crypto Monitor

## Core Features:

- Live Value Tracking: Display real-time crypto values from the CoinGecko API, focusing on a user-selected cryptocurrency
- Progress Display: Show the current cryptocurrency's daily progress towards a target goal
- AI Crypto Assistant: Allow the user to ask questions about crypto, powered by a generative AI tool connected to up-to-date market data. The AI tool determines when it can retrieve price information for the currency in question, or, it answers in the normal way without market information if possible. 
- Integrated News Feed: Provide news headlines relevant to the displayed cryptocurrencies
- Periodic Data Update: Fetch market data periodically from the CoinGecko API.
- Intuitive UI: Use a simple and clean design based on the provided screenshot for an intuitive user experience.

## Style Guidelines:

- Background color: Dark blue-gray background (#121829) to provide a modern look, enhance readability, and reduce eye strain.
- Primary color: Bright cyan (#00ffff) for emphasis on key metrics and interactive elements.
- Accent color: Light blue (#7DF9FF) used in subtle accents throughout the interface, such as the progress bar and borders, to add depth without overwhelming the user.
- Body and headline font: 'Inter', a sans-serif font, offering a modern, neutral, and easily readable style suitable for displaying financial information and news snippets.
